# Kontinuitet och revisionsgränser

1. Kartlägg tidigare etablerade fakta utan att hitta på bakgrund.
2. Respektera användarens senaste uttryckliga ändring och bibehåll annars tidigare text.
3. Vid fortsättning: bevara karaktärsutveckling och tidslinje.
4. Vid revision: matcha ändringens omfång mot uppgiften.
5. Vid motsägelser som väsentligt påverkar handlingen: fråga kort eller redovisa konflikten.

## Acceptanskriterier

- Språkputs ändrar inte intrig eller perspektiv.
- Ökad spänning innebär inte automatiskt mer våld.
- Fortsättning återställer inte karaktären till tidigare utvecklingsstadium.
- Ett omarbetat slut utgår från etablerad konflikt och motiv.

Fullständiga regler finns i `canonical/instructions.md`.
